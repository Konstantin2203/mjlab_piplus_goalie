# PiPlus mjlab project

![PiPlus](docs/piplus_viser.png)

This project builds on the [mjlab](https://github.com/mujocolab/mjlab) project to create a mjlab project for the PiPlus robot for various RL tasks.

## Installation

Install uv
```bash
uv sync
```

## Train a policy

```bash
uv run train Mjlab-Velocity-PiPlus
```
